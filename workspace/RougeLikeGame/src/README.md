# RougeLike Game - Dungeon Crawler

Проект вдохновлён Shattered Pixel Dungeon. Это roguelike dungeon crawler с видом сверху, процедурной генерацией уровней и пиксельной графикой.

## Особенности

- **6 героев** с уникальными классами и механиками
- **Процедурная генерация** подземелий
- **Пиксельная графика** и анимации
- **Система талантов**, предметы, ловушки
- **Пошаговая боевка**
- **Перманентная смерть**

## Требования

- Windows 10/11
- C++20 компилятор (MSVC)
- CMake 3.20+
- SFML 3.x
- vcpkg

## Управление

- **WASD** - движение
- **Пробел** - атака
- **E** - использовать предмет
- **ESC** - выход

## Сборка

```bash
cmake -B build -S .
cmake --build build --config Release
```

## Запуск

```bash
build/rougeLikeGame.exe
```
